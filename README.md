# Mobile Price Range Predictor

A machine learning web application that predicts mobile phone price ranges based on hardware specifications.

## Features
- Predicts mobile price categories from device specifications.
- Uses a trained machine learning model.
- Interactive interface built with Gradio.
- Deployed on Hugging Face Spaces.

## Tech Stack
- Python
- Scikit-learn
- Pandas
- Gradio
- Machine Learning
